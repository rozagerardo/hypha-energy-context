# henergy-start — the front door (for anyone)

**Triggers:** "hi", "hey", "let's get started", "what is this / what can you do", "I want to try
this", "help me get oriented", just opened/cloned the repo with no specific goal.

**Who it's for:** Anyone — technical developers, conceptual contributors, strategic stakeholders,
newcomers. The welcoming, zero-prerequisite entry point for the whole team.

Greets, orients in one sentence, asks 1–2 questions, then routes:

- **Technical + ready** → run `henergy-dev-setup`, then `henergy-task-init` when they have a ticket
- **Non-technical** → guided tour of `solution/`, `progress/` — no setup needed
- **Just exploring** → README → `AGENTS.md` → `solution/overview.md`

**Procedure:** [`workflow/get-started.md`](../../../workflow/get-started.md)
